# FOOTBALL-SQL-ANALYSIS


## overview
SQL analysis of European football statistics from the Top 5 leagues (Premier League, La Liga, Serie A, Bundesliga, Ligue 1) spanning from 2014 to 2020.

## Dataset
Data sourced from Kaggle - Football Database by Technika148.
Contains 7 tables: appearances, games, leagues, players, shots, teams, teamstats.

## Analysis
- Top 10 teams by total wins across all seasons
- Top 10 teams by total goals scored
- More analysis coming soon

## Tools Used
- SQLite
- Jupyter Notebook
- Pandas
- ipython-sql
